One original one-line joke about office life, written for the make.fun bounty "One-Line Office Joke: 24-Hour Sprint". The program writes the joke to `/output/entry.txt`, where the sealed scorer reads it.

The joke: a daily standup scheduled for fifteen minutes, running forty-five, and still ending with the office's favourite escape hatch — "let's take this offline."

## Run it

```sh
node main.ts
```
